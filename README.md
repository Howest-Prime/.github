# Howest Prime

Howest Prime brings together an Android mobile application, backend services for movies and ticketing, and infrastructure repositories for production and testing.

## Project overview

The project is organized into separate repositories for the mobile client, movies service, ticketing service, and infrastructure environments.

## Repositories

| Repository | Description |
| --- | --- |
| [st-client-mobile](https://github.com/Howest-Prime/st-client-mobile) | Android mobile application. |
| [st-microservice-movies](https://github.com/Howest-Prime/st-microservice-movies) | Movies microservice. |
| [st-microservice-ticketing](https://github.com/Howest-Prime/st-microservice-ticketing) | Ticketing microservice. |
| [st-infrastructure-prod](https://github.com/Howest-Prime/st-infrastructure-prod) | Production infrastructure. |
| [st-infrastructure-test](https://github.com/Howest-Prime/st-infrastructure-test) | Test infrastructure. |

## Architecture

The repository layout separates the Android client from the movies and ticketing backend services. Production and test infrastructure are maintained in their own repositories. See each repository’s README for its technologies, setup, and implementation details.
